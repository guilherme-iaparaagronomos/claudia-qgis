about=ClaudIA QGIS connects the QGIS running on your computer to the agrônomo10X
    community (OagronomIA). Your AI assistant — Claude, ChatGPT or any MCP
    client — gets 100+ tools to inspect and operate your project: layers,
    attributes, Processing algorithms, styling, map rendering, print layouts
    and more. No Python setup, no open ports: the plugin long-polls the
    community over HTTPS and posts the results back.

    Requires an agrônomo10X community account with ClaudIA QGIS enabled:
    https://comunidade.agronomos.ia.br/solucoes/mcp/claudia-qgis

    What the plugin sends to the community: the QGIS version, the name of the
    open project and the results of the commands YOUR AI requests. Nothing
    leaves without a command from you; the token can be revoked on your page
    at any time. Interface in English or Brazilian Portuguese (follows the
    QGIS language; selectable in the connection window).

    Free software (GPLv2+). Derived from "QGIS MCP" by Nicolas Karasiak
    (https://github.com/nkarasiak/qgis-mcp, GPLv2+): the command handlers that
    run inside QGIS are his work; ClaudIA QGIS replaces the local socket
    server with the community connection.

    ---

    ClaudIA QGIS conecta o QGIS aberto no seu computador à comunidade
    agrônomo10X (OagronomIA). A sua IA — Claude, ChatGPT ou qualquer cliente
    MCP — recebe mais de 100 ferramentas para enxergar e operar o seu projeto:
    listar e adicionar camadas, ler atributos, rodar algoritmos do Processing,
    aplicar estilos, renderizar o mapa, montar layouts de impressão e muito
    mais. Sem instalar Python, sem abrir portas: o plugin busca os comandos na
    comunidade por HTTPS e devolve os resultados.

    É preciso ter conta na comunidade agrônomo10X com a solução ClaudIA QGIS
    liberada: https://comunidade.agronomos.ia.br/solucoes/mcp/claudia-qgis

    O que o plugin envia à comunidade: a versão do QGIS, o nome do projeto
    aberto e o resultado dos comandos que a SUA IA pedir. Nada sai sem um
    comando seu; o token pode ser revogado na sua página a qualquer momento.
    Interface em inglês ou português do Brasil (segue o idioma do QGIS;
    escolha na janela de conexão).

changelog=0.4.2 : interface in English or Brazilian Portuguese — the plugin
    follows the QGIS language (any language other than Portuguese shows
    English) and the connection window has a language selector (Automatic /
    Português / English). Plugin description and this changelog now in
    English. No change to the tools.
    0.4.1 : fix: "Update now" (and disconnect) could close QGIS without
    warning — on Windows, closing the socket from another thread does not wake
    the long-poll in progress; the thread outlived the wait timeout and was
    destroyed while still running. The socket is now shut down and the thread
    is never destroyed alive. No change to the tools.
    0.4.0 : handlers updated to nkarasiak/qgis-mcp v0.15.0 — background
    processing jobs (start_processing_job, get_processing_job,
    cancel_processing_job: no time cap and QGIS does not freeze), project
    checkpoints (create_checkpoint, list_checkpoints, restore_checkpoint) and
    export_session (a Python script that replays the session); partial results
    or failures no longer pass as success (Processing reason, dropped features
    in warnings); load_project no longer hangs on an unavailable layer; crs in
    identify_features, sample_raster_values and add_features; ellipsoid in
    Processing; inline QML in apply_style_qml. Includes 0.3.0 below, which
    never reached the portal.
    0.3.0 : handlers updated to nkarasiak/qgis-mcp v0.14.1 — attribute
    converter with dates, fixes in features, processing, connections and
    system, unresolved enums no longer crash the plugin (compat), and
    supportsQt6 declared: Qt6 builds of QGIS 3.x load the plugin again.
    execute_sql accepts limit.
    0.2.3 : plugin portal security scan (Bandit) cleared: the updater
    downloads through http.client over http/https only (no file: or custom
    schemes), following the GitHub redirect; empty try/except blocks became
    contextlib.suppress with the right exception.
    0.2.2 : metadata homepage points to the public repository (the connector
    page in the community requires login; the portal reviewer needs an open
    link). No code change.
    0.2.1 : the "Community address" field accepts any URL of the site
    (including the connector page) and keeps only the domain.
    0.2.0 : self-update — the community announces the latest version on every
    command poll; when there is a new one, an "Update now" bar appears (and the
    menu gains "Update the plugin…"): the plugin downloads the release ZIP,
    swaps the files and reloads itself, reconnecting afterwards. Connection
    state visible on the toolbar button ("ClaudIA · CONNECTED"), on the icon
    and in the status bar; warning when the community does not respond.
    0.1.0 : first version — connection to the agrônomo10X community by HTTPS
    long-poll (plugin token generated on the community page), 120 commands
    inherited from QGIS MCP 0.14.0 by Nicolas Karasiak, interface in
    Portuguese, no local server and no MCP client configuration.
