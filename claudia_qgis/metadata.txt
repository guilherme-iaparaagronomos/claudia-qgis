about=🇺🇸 ENGLISH
    Your AI (Claude, ChatGPT or any MCP-compatible AI) operates the QGIS open on your computer: layers, attributes, Processing, styles and print layouts.

    How to connect:
    Step 1: Create your account (free) in the agrônomo10X community and generate the connection token:
    https://comunidade.agronomos.ia.br/login
    Step 2: In QGIS, click the ClaudIA button → Connect to the community… and paste the token.
    Step 3: In your AI of choice, add a custom MCP connector with the link below and sign in with your community account:
    https://comunidade.agronomos.ia.br/api/mcp/qgis

    Video tutorial, step by step:
    https://www.youtube.com/watch?v=i3kPZWyq3Co

    For more information, visit https://www.agronomos.ia.br/en

changelog=0.4.7 : plans by usage — the plugin now shows the two account states
    of the new community plans. On the free plan: the requests used today
    (for example "3 of 7 requests today") in the toolbar button, the status bar
    and the menu, and one notice with a "See the plans" button when the day's
    requests run out (they come back at midnight, Brasília time). On a
    subscription: the monthly usage as a percentage, with the renewal date in
    the menu, one notice when it passes 80% and one, with the "See the plans"
    button, when it runs out. Older servers keep working as before. No change
    to the tools.
    0.4.6 : video tutorial on how to connect, in English, Portuguese,
    Spanish and French — in this description, in the menu (ClaudIA button and
    Plugins → ClaudIA QGIS → "Video tutorial: how to connect", which opens the
    video in the interface language) and as a button in the welcome window.
    Safer "Update now": the plugin only downloads a ZIP published in the
    releases of the ClaudIA QGIS repository on GitHub, and follows redirects
    only to GitHub's download servers. No change to the tools.
    0.4.5 : the free-requests line also shows in the Plugins menu
    (Plugins → ClaudIA QGIS), right below the connection status — in 0.4.4 it
    was only in the toolbar button menu. Includes 0.4.4 below, which never
    reached the portal.
    0.4.4 : free trial by requests — when the community counts the free trial in
    requests (a request is what you ask your AI, however many tools it uses),
    the toolbar button and the status bar show the free requests left, the menu
    shows them with the trial end date, the message bar warns when 2 or fewer
    are left and, at zero, shows a "See the plans" button; with a plan that
    includes ClaudIA QGIS the menu says "Unlimited requests". New "no access"
    state: when the account no longer has ClaudIA QGIS (free trial ended, plan
    without it, payment overdue), the button shows "ClaudIA · no access" in
    orange instead of "no connection", the message bar explains it with a "See
    the plans" button, and the plugin reconnects on its own, with the same
    token, as soon as the access comes back. Texts in English, Portuguese,
    Spanish and French. Command handlers unchanged (nkarasiak/qgis-mcp v0.15.2
    reviewed: nothing to port). No change to the tools.
    0.4.3 : interface in English, Portuguese, Spanish and French — the
    plugin follows the QGIS language (any other language shows English) and
    the language selector has the four. Command handlers updated to
    nkarasiak/qgis-mcp v0.15.1 — PostGIS tables added by name
    (add_layer_from_connection) now load with their geometry instead of as
    plain attribute tables. New plugin description: each language starts
    with its flag and name, with the three connection steps; the welcome
    window shows the connector address; the "Advanced" section (community
    address) only appears for test setups. No change to the tools.
    0.4.2 : interface in English or Brazilian Portuguese — the plugin
    follows the QGIS language (any language other than Portuguese shows
    English) and the connection window has a language selector (Automatic /
    Português / English). Plugin description and this changelog now in
    English. No change to the tools.
    0.4.1 : fix: "Update now" (and disconnect) could close QGIS without
    warning — on Windows, closing the socket from another thread does not wake
    the long-poll in progress; the thread outlived the wait timeout and was
    destroyed while still running. The socket is now shut down and the thread
    is never destroyed alive. No change to the tools.
    0.4.0 : handlers updated to nkarasiak/qgis-mcp v0.15.0 — background
    processing jobs (start_processing_job, get_processing_job,
    cancel_processing_job: no time cap and QGIS does not freeze), project
    checkpoints (create_checkpoint, list_checkpoints, restore_checkpoint) and
    export_session (a Python script that replays the session); partial results
    or failures no longer pass as success (Processing reason, dropped features
    in warnings); load_project no longer hangs on an unavailable layer; crs in
    identify_features, sample_raster_values and add_features; ellipsoid in
    Processing; inline QML in apply_style_qml. Includes 0.3.0 below, which
    never reached the portal.
    0.3.0 : handlers updated to nkarasiak/qgis-mcp v0.14.1 — attribute
    converter with dates, fixes in features, processing, connections and
    system, unresolved enums no longer crash the plugin (compat), and
    supportsQt6 declared: Qt6 builds of QGIS 3.x load the plugin again.
    execute_sql accepts limit.
    0.2.3 : plugin portal security scan (Bandit) cleared: the updater
    downloads through http.client over http/https only (no file: or custom
    schemes), following the GitHub redirect; empty try/except blocks became
    contextlib.suppress with the right exception.
    0.2.2 : metadata homepage points to the public repository (the connector
    page in the community requires login; the portal reviewer needs an open
    link). No code change.
    0.2.1 : the "Community address" field accepts any URL of the site
    (including the connector page) and keeps only the domain.
    0.2.0 : self-update — the community announces the latest version on every
    command poll; when there is a new one, an "Update now" bar appears (and the
    menu gains "Update the plugin…"): the plugin downloads the release ZIP,
    swaps the files and reloads itself, reconnecting afterwards. Connection
    state visible on the toolbar button ("ClaudIA · CONNECTED"), on the icon
    and in the status bar; warning when the community does not respond.
    0.1.0 : first version — connection to the agrônomo10X community by HTTPS
    long-poll (plugin token generated on the community page), 120 commands
    inherited from QGIS MCP 0.14.0 by Nicolas Karasiak, interface in
    Portuguese, no local server and no MCP client configuration.
